# Forward Records

This directory is the append-only evidence ledger for Oracle Canonical Signal v1.

Each date-named JSON file is generated by the scheduled Forward Observation workflow after the US market close. The record includes its source-data cutoff and SHA-256 input-history fingerprint. A pre-existing date file is never silently overwritten.

Important: a record can have a stale data cutoff if the upstream daily source has not published the latest session when the workflow runs. Read `data_cutoff`; do not infer freshness from the Git commit timestamp.

These observations are research evidence, not trade instructions.
